What it catches

Terminal

Paste-jacking, base64-decoded shells, reverse shells, remote fetch-to-shell, and destructive commands.

Browser Console

Blocks eval(), remote fetch(), malicious workers, DOM injection, and credential exfiltration.

AI Chat Inputs

Detects instructions to paste malicious commands, hidden social-engineering prompts, and obfuscated payloads.

Architecture

A single JSON rule engine powers the terminal CLI, the browser userscript, and AI chat input guards. Add or modify rules without touching code.

Hermes / AI output guard

integrations/hermes_guard.py checks every assistant message before it reaches the user. Dangerous outputs are blocked; suspicious ones are flagged.
